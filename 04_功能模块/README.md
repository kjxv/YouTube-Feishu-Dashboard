# 04 功能模块

这里是各个业务板块的实体分区。每个子目录对应一个明确业务目标，并拥有独立、稳定的英文 Python 包名。

| 中文业务分区 | Python 包 | 当前状态 |
|---|---|---|
| `01_最新发布视频实时追踪` | `yfd_latest_video_tracker` | V1 已实现 |
| `02_频道历史数据` | `yfd_channel_history` | 接口模板 |
| `03_全部视频当前数据` | `yfd_all_videos_current` | 接口模板 |

模块应该声明字段需求、实现本模块业务流程和调度任务适配器；公共框架负责凭证、API 客户端、数据库、飞书写入、锁、重试、日志和归档。

新增模块时复制的是目录组织和清单模式，不复制公共客户端或数据库代码。具体约束见 `00_项目文档/模块开发规范.md`。
