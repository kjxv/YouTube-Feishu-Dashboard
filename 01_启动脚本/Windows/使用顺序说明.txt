日常最常用：
  先在飞书“账号非敏感配置”的 tracking_video_ids 填写 1～10 个视频 ID。
  双击 6.运行一次_最新视频.bat
  作用：读取同一份手动视频列表，立即获取 YouTube 真实数据，并幂等同步主表、快照表、同期对比表。

频道每日统计：
  首次接入48小时榜字段时，可双击 13.补建频道48小时字段.bat；它只补缺失项，可重复执行。
  双击 11.只读检查_频道数据.bat，先检查三张频道业务表、字段和映射。
  运行电脑升级后，可双击 15.启用并首次同步频道数据.bat；它会先检查、再开启、再同步，失败会自动关闭。
  已经启用后的普通人工补跑，可双击 12.运行一次_频道数据.bat。
  频道任务只统计长视频；Shorts、直播和非公开视频不会写入这三张表。

需要自动运行时：
  双击 10.自动定时任务管理.bat
  第一次选择“安装或更新”；以后可在同一入口查看状态、暂停、恢复或卸载。
  自动任务每个整点唤醒，程序内部按视频分别判断：
    - 发布后前 72 小时：Data API 每小时最多采集一次；
    - 72 小时后至第 28 天：每天北京时间 08:00 采集；
    - 另保留发布满 7、14、28 天时的节点采集；
    - Analytics API 每天 08:00 刷新；Reporting API 每 6 小时检查一次。
  同一个自动任务也会管理频道每日统计：北京时间 08:00 后每天运行一次。

第一次安装或重新授权时才用：
  1.首次配置.bat
  2.YouTube授权.bat
  3.初始化飞书配置中心.bat
  4.中文化升级飞书配置表.bat

排查问题时用：
  5.系统检查.bat
  8.只读预览_最新视频.bat（在线核对列表中的视频是否可访问、是否属于当前频道；不写三张业务表）
  9.只读检查_三表配置.bat（检查视频 ID 格式、数量、重复项以及飞书结构与映射；不请求 YouTube，不写三张业务表）
  11.只读检查_频道数据.bat（只读检查频道模块配置、三张表和映射）

不要日常双击：
  7.调度滴答.bat
  这是底层整点入口。请用 10.自动定时任务管理.bat 安装，不要手工建立多个计划任务。

换电脑：
  1. 把项目、.env 和所需凭据安全迁移到新电脑，或在新电脑重新授权。
  2. 已有运行环境时，更新项目后双击 14.运行电脑升级并验收.bat；没有运行环境才先运行 1.首次配置.bat。
  3. 第14个入口通过后，再运行 10.自动定时任务管理.bat，选择“安装或更新”。
  4. 双击 15.启用并首次同步频道数据.bat，核对飞书结果正常后再恢复统一计划任务。
  5. 确认新电脑运行正常后，暂停或卸载旧电脑任务；不要两台电脑同时启用。
  6. 频道模块会按唯一键安全认领飞书已有记录，不要复制数据库覆盖新电脑原有任务状态。
