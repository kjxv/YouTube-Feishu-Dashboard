# 自动定时采集说明

## 一、现在采用的规则

Windows 每个整点唤醒程序一次。唤醒不等于一定请求 API；程序会按每个视频自己的发布时间和最后一次真实采集记录判断。

- Data API：发布后前 72 小时，每个北京时间整点最多采集一次。
- Data API：超过 72 小时后，到第 28 天为止，每天北京时间 08:00 采集一次。
- Data API：在发布满 7、14、28 天的实际时刻增加节点采集。视频通常在 20:00 发布，因此节点通常也是 20:00。
- Analytics API：每天北京时间 08:00 刷新一次。
- Reporting API：每天 02:00、08:00、14:00、20:00 检查新日报。报表本身仍由 YouTube 按天生成，多检查不会把日报变成小时数据。
- 第 28 天最终采集完成后停止例行追踪。

电脑关机或休眠时不会采集，也不会伪造缺失的小时记录。电脑恢复后，第一次整点检查会做一次当前真实采集；如果错过第 28 天最终节点，会在恢复后补一条真实最终记录。

## 二、Windows 使用方法

双击 `01_启动脚本/Windows/10.自动定时任务管理.bat`，可以：

1. 安装或更新当前电脑的定时任务；
2. 查看上次结果和下次运行时间；
3. 暂停或恢复；
4. 立即按定时规则检查一次；
5. 从当前电脑卸载。

第 6 步仍是“强制立即采集”，不受是否到达整点或是否已经采集过的限制。管理工具中的“立即检查”则会遵守自动定时规则，两者用途不同。

运行日志位于 `runtime/logs/windows-scheduler.log`。

## 三、换电脑

计划任务属于 Windows 本机，复制项目不会把任务本身复制过去。新电脑上应：

1. 安全迁移项目配置和凭据，或重新完成 YouTube 授权；
2. 运行 `1.首次配置.bat`，为新电脑建立运行环境；
3. 运行 `10.自动定时任务管理.bat` 并选择“安装或更新”；
4. 查看状态确认成功；
5. 暂停或卸载旧电脑的任务。

同一套飞书表格只允许一台电脑启用自动任务，避免重复写入和同时请求 API。

## 四、飞书“数据项目配置”应使用的值

- `latest_interval_minutes` = `60`
- `latest_hourly_tracking_hours` = `72`
- `latest_daily_collection_hour` = `8`
- `latest_analytics_interval_hours` = `24`
- `latest_reporting_interval_hours` = `6`
- `latest_tracking_days` = `28`

旧表中没有的配置键需要补充；已有的 7 天、24 小时等旧值需要改成上面这些值。远端飞书配置启用后优先于本地默认值。
