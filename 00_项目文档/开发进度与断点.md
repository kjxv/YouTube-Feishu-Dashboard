## 关键决策

1. Python 要求 3.11+；顶层使用中文职责分区，内部使用稳定英文 `src` 包布局。
2. V1 使用 SQLAlchemy 2.x + Alembic；SQLite 是默认运行库，PostgreSQL 通过数据库 URL 与可选 `psycopg` 依赖接入。
3. CLI 使用 Python 标准库 `argparse`，减少部署依赖；Windows 和 Linux 脚本只包装 CLI。
4. API 字段目录保存为版本化 JSON 资源；飞书映射负责决定模块实际使用哪些字段。
5. 调度状态和锁必须在公共数据库中持久化，机器断电后按真实当前时间判断到期，不回填虚构快照。
6. 不自动提交、不推送；到关键节点只检查并报告 Git 状态。
7. 公共包名固定为 `youtube_feishu_dashboard`；业务包使用 `yfd_...`，不能再放回公共包的 `modules/` 子目录。
8. Windows 不使用包含中文源码路径的 editable install；首次配置安装普通 wheel，避免 `.pth` 系统代码页问题。
9. 飞书公共配置表以精确中文表名复用；初始化器不删除、不重命名、不自动改变已有字段类型，发现冲突即停止。
10. 业务字段映射存在飞书配置中心时，只使用已启用的远端映射；禁用记录不能被代码默认值重新启用。
11. 英文配置键和标准字段ID属于稳定程序接口，不翻译、不随飞书中文列名变化；所有用户说明放在独立中文字段。
12. 关键字段使用飞书原生“字段说明”标记，不给字段名加前后缀，避免破坏程序识别。
13. API目录按“旧版基线 + 新版增量”维护；业务表的系统生成、系统计算、飞书公式与关联字段不得伪装成官方API字段。
