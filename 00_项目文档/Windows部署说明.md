# Windows 部署说明

## 本地运行

使用 `01_启动脚本/Windows` 下的中文 `.bat`。包装脚本会定位自身所在仓库，不依赖固定盘符；核心逻辑始终调用同一个 Python CLI。

- `首次配置.bat`：创建虚拟环境、安装项目并运行向导
- `YouTube授权.bat`：完成一次 OAuth 授权
- `系统检查.bat`：本地与飞书在线检查
- `运行一次_最新视频.bat`：手工运行真实任务
- `调度滴答.bat`：供 Windows 计划任务调用，不弹交互提示

## 计划任务建议

Windows 只负责每 5～10 分钟触发一次：

```text
runtime\venv\Scripts\python.exe -m youtube_feishu_dashboard scheduler tick
```

“每 30 分钟抓取”由数据库中的真实到期时间控制，不由计划任务文件复制业务逻辑。电脑每天 7:50 开机后，第一次 tick 会处理已经到期的任务；午夜关机期间不创建快照。

计划任务应设置：使用项目虚拟环境 Python、工作目录为仓库根目录、失败后允许再次触发、不要并行启动同一任务。即使操作系统误并行，公共数据库锁仍会阻止重复执行。

触发程序可以直接选择 `01_启动脚本/Windows/调度滴答.bat`。触发频率 5～10 分钟只是让调度器及时醒来；不会把业务采集间隔改成 5～10 分钟。

## 迁移 VPS 前

提交代码和迁移，备份数据库；不要提交 `.env`、`secrets`、日志或 Token。SQLite 可先用于单机迁移验证，正式长期运行推荐导入 PostgreSQL。
