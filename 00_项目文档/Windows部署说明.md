# Windows 部署说明

## Windows 全新电脑首次部署

1. 安装 Python 3.11，并确认 Windows Python Launcher 可用。
2. 从 GitHub 下载项目；不要把 `.env`、OAuth 文件、Token 或数据库提交到 Git。
3. 双击 `1.首次配置.bat`，按照提示填写本机 `.env` 所需配置。
4. 把 Google OAuth 客户端文件放入 `secrets/youtube_client_secret.json`。
5. 双击 `2.YouTube授权.bat` 完成 YouTube 授权。
6. 双击 `3.初始化飞书配置中心.bat` 创建或补齐飞书公共配置表。
7. 双击 `5.系统检查.bat`；通过后依次运行 `9`、`8` 做只读检查。
8. 双击 `6.运行一次_最新视频.bat` 完成一次真实同步。
9. 双击 `11.只读检查_频道数据.bat`；需要首次启用频道模块时运行 `15.启用并首次同步频道数据.bat`。
10. 核对飞书无误后，双击 `10.自动定时任务管理.bat`，选择“安装或更新”。

从旧运行电脑迁移时，应先暂停旧电脑计划任务并等待当前任务结束，再安全复制 `.env`、
`secrets/youtube_client_secret.json`、`secrets/youtube_token.json` 和 `data/yfd.db`。新电脑先运行
`14.运行电脑升级并验收.bat`，完成真实测试后再启用计划任务。两台电脑不能同时运行。

## 本地日常运行

使用 `01_启动脚本/Windows` 下带编号的中文 `.bat`。包装脚本会定位自身所在仓库，不依赖固定盘符；核心逻辑始终调用同一个 Python CLI。

- `1`～`4`：仅用于首次配置、授权和飞书公共配置初始化/升级。
- `5.系统检查.bat`：本地与飞书在线检查。
- `6.运行一次_最新视频.bat`：日常手工运行一次真实三表同步。
- `7.调度滴答.bat`：只供 Windows 计划任务调用，不弹交互提示。
- `8.只读预览_最新视频.bat`：只读取 YouTube，不写业务表。
- `9.只读检查_三表配置.bat`：只读核对飞书三表结构和映射。

完整使用顺序见 [日常使用与扩展指南](日常使用与扩展指南.md)。

## 计划任务说明

Windows 在每个整点触发一次：

```text
runtime\venv\Scripts\python.exe -m youtube_feishu_dashboard scheduler tick
```

是否真正抓取由数据库中的真实到期时间控制，不由计划任务文件复制业务逻辑。电脑错过整点后，
恢复运行时会处理已经到期的任务；关机期间不创建或伪造快照。

计划任务应设置：使用项目虚拟环境 Python、工作目录为仓库根目录、失败后允许再次触发、不要并行启动同一任务。即使操作系统误并行，公共数据库锁仍会阻止重复执行。

底层触发程序是 `01_启动脚本/Windows/7.调度滴答.bat`，只供计划任务调用，不应作为日常
手动同步入口。安装、暂停、恢复和状态检查统一使用 `10.自动定时任务管理.bat`。

## 迁移 VPS 前

提交代码和迁移，备份数据库；不要提交 `.env`、`secrets`、日志或 Token。SQLite 可先用于单机迁移验证，正式长期运行推荐导入 PostgreSQL。
