# 首次使用说明

## 准备

- Python 3.11+
- 已启用 YouTube Data API v3、YouTube Analytics API、YouTube Reporting API 的 Google Cloud 项目
- Google OAuth 桌面应用客户端 JSON
- 有多维表格读写权限的飞书企业自建应用

## 推荐流程

1. 运行对应系统的“首次配置”脚本，它会创建虚拟环境、安装依赖、复制 `.env.example`、创建安全目录并初始化数据库。
2. 在飞书开放平台开通 `bitable:app`、发布应用，并把文档应用加入目标多维表格；敏感 App Secret 只写 `.env`。
3. 把 OAuth 客户端文件放入 `secrets/youtube_client_secret.json`。
4. 运行 `yfd scheduler run-once latest-video-tracker --dry-run`；此命令不联网，可先检查字段请求计划和缺失配置。
5. 运行 `yfd auth youtube` 完成一次 OAuth 授权。
6. 运行 `yfd doctor --online` 检查配置、数据库、Token 与飞书连通性。
7. 双击“初始化飞书配置中心”脚本，或运行 `yfd feishu bootstrap-config`。系统会幂等创建四张公共表、补齐缺失字段、写入初始配置与 API 字段目录，并把四个 Table ID 回写到 `.env`。
8. 去掉 `--dry-run` 实际运行一次最新视频任务。
9. 验证飞书业务表后，再配置 Windows 计划任务或 VPS timer 定期调用 `yfd scheduler tick`。

配置中心初始化器不会删除表、字段或记录，也不会覆盖已经存在的项目配置；重复运行时复用同名表，只创建缺失内容。若已有同名表的字段类型冲突，它会停止并报告，不会自动改写用户数据。旧版配置表可运行 `yfd feishu localize-config` 就地升级为中英文对照结构。

首次配置重复运行不会覆盖已有 `.env`。实际命令以 `yfd --help` 为准；向导不会把密钥写入 Git 跟踪文件，也不会替用户提交或推送仓库。
